# MANUAL DE USUARIO - MateKids

## Bienvenida a MateKids 🚀

¡Hola! Este manual te ayudará a usar **MateKids**, la aplicación para aprender matemáticas de forma divertida reparando máquinas en una estación científica futurista.

---

## 📱 Instalación

### Requisitos

- Dispositivo Android 7.0 o superior
- Mínimo 50MB de espacio disponible
- Conexión de Internet para descargar (la app funciona sin Internet después)

### Pasos de Instalación

1. **Descargar APK**
   - Descarga `MateKids-v1.0.0.apk` desde GitHub
   - O desde Google Play Store (cuando esté disponible)

2. **Instalar en tu dispositivo**
   - Abre el archivo APK
   - Toca "Instalar"
   - Espera a que termine
   - Toca "Abrir" para iniciar

3. **Permitir permisos**
   - La app solicita permiso de almacenamiento
   - Toca "Permitir"
   - ¡Ya estás listo!

## 🧮 Módulos de Aprendizaje

### 1️⃣ Sumadora Cuántica (Suma)

**¿Qué es?** Resuelve problemas de suma hasta 100

**Cómo jugar:**
1. Aparecerá una suma: `5 + 3 = ?`
2. Ingresa tu respuesta: `8`
3. Toca "Responder"
4. Si es correcta: ✅ +10 XP
5. Si es incorrecta: ❌ Intenta de nuevo

**Consejos:**
- No hay límite de intentos
- Aprenderás del error
- Cada respuesta correcta suma XP

---

### 2️⃣ Restadora de Equilibrio (Resta)

**¿Qué es?** Resuelve problemas de resta hasta 100

**Ejemplo:**
```
20 - 7 = ?
Respuesta: 13
```

**Regla**: El primer número siempre es mayor (no hay negativos)

---

### 3️⃣ Multiplicadora de Energía (Multiplicación)

**¿Qué es?** Tablas de multiplicar hasta 12×12

**Ejemplo:**
```
6 × 7 = ?
Respuesta: 42
```

**Reto**: Aumenta de dificultad conforme avanzes

---

### 4️⃣ Divisora Precisa (División)

**¿Qué es?** Divisiones con resultado entero

**Ejemplo:**
```
24 ÷ 6 = ?
Respuesta: 4
```

**Nota**: Solo divisiones exactas para evitar confusión

---

### 5️⃣ Cálculo Mental

**¿Qué es?** Desafíos contrarreloj

**Cómo juega:**
1. Tienes 30 segundos
2. Resuelve 5 operaciones
3. Barra de tiempo visible
4. Bono de XP si terminas a tiempo

**Dificultad**: Progresiva (fácil → media → difícil)

---

### 6️⃣ Fábrica de Desafíos

**¿Qué es?** Retos únicos y variados

**Ejemplos:**
- 🎯 **Falla Crítica**: Problema de dos operaciones
- ⚖️ **Equilibrio de Energía**: Arrastra números para equilibrar
- 🔄 **Recalibración**: Ordena operaciones

**Recompensa**: 20 XP por desafío (mayor que operaciones normales)

## 💡 Consejos para Mejorar

### Para Aprender Mejor

1. **Empieza con lo básico**
   - Comienza en Suma
   - Luego Resta
   - Luego Multiplicación y División

2. **Practica regularmente**
   - 15-20 minutos diarios
   - Mejor que 1 hora una sola vez

3. **Usa Cálculo Mental para desafío**
   - Más XP en menos tiempo
   - Entrena velocidad

4. **No temas los errores**
   - Cada error es aprendizaje
   - Sin castigos, solo corrección

### Para Desbloquear Insignias

- Reparar máquinas: Resuelve 5 de ese tipo
- Mente Rápida: Termina cálculo mental a tiempo
- Genio Matemático: Llega al nivel 20

### Racha de Días

- Abre la app 1 vez al día
- Tu racha sube automáticamente
- Bono motivador para volver

## 🆘 Preguntas Frecuentes

### ¿Necesito Internet?

**No.** La app funciona completamente sin Internet. Solo necesitas conexión para descargar.

### ¿Se guardan mis datos?

**Sí.** Todo se guarda automáticamente en tu dispositivo. Si reinstalar la app, perderás datos (no hay backup en nube).

### ¿Hay límite de intentos?

**No.** Puedes reintentar infinitas veces sin penalización.

### ¿Puedo jugar varios usuarios?

**No.** Versión 1.0 es un usuario por dispositivo. La versión 2.0 incluirá multi-usuario.

### ¿Cuántas operaciones hay?

**Ilimitadas.** Se generan aleatoriamente según el tipo y dificultad.

### ¿Qué hago si me quedo atascado?

1. Reinicia la app (no pierdes datos)
2. Intenta otro módulo
3. Vuelve después

### ¿Por qué algunos números no aparecen?

**División**: Solo muestra divisiones exactas (sin decimales)
**Suma/Resta**: Rango de números adecuado a tu nivel
